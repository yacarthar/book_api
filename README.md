
# Book API
[![Test & Deploy](https://github.com/yacarthar/book_api/actions/workflows/test_deploy.yml/badge.svg?branch=main&event=push)](https://github.com/yacarthar/book_api/actions/workflows/test_deploy.yml)

A RESTful API for book management, using FastAPI framework and PostgreSQL database.

**Live demo**:

- https://jimmypham.xyz/api/v1/redoc
- https://jimmypham.xyz/api/v1/books/?page=1&limit=5
- https://jimmypham.xyz/api/v1/books/?title=en&date=before2022-11-09&page=3&limit=5
- https://jimmypham.xyz/api/v1/books/?title=en&date=after2014-11-19&limit=5
- https://jimmypham.xyz/api/v1/books/?date=2015-09-16

## Features

- CRUD book items:
    - Read, update, and delete items
    - List items with pagination
        - Filter by keyword
        - Filter by date
- Authenticate User with Bearer Token:
    - Protected routes: Create Book, Delete Book, Update Book
- CI/CD:
    - Job only deploys after all tests pass
- Tests:
    - Functional tests: test if all endpoints work as expected when communicating with a test database
    - Endpoint tests: test each endpoint in isolation, with mock class.
- Redoc Documentation
    - Documentation autogenerated by default
    - Access at `/api/v1/redoc`

## Tech Stack

**Framework:** Python, FastAPI

**Database:** PostgreSQL on Supabase

**Hosting:** VPS Ubuntu 24.04

**CI/CD:** GitHub Actions

## Run locally

1. Clone the project
```bash
git clone https://github.com/yacarthar/book_api.git
cd book_api
```

2. Create a `.local.env` file, based on `.env.example`

3. Start the application with Docker Compose:
```bash
docker compose -f docker-compose.local.yml up
```


### Prerequisites
- A PostgreSQL database up and running for the local environment.

### Environment Variables

To run/test this project locally, you must add the following environment variables to your `.local.env` file or `.test.env` (when you run tests).

I recommend you look up `.env.example` for more details.

`SECRET_KEY`: enter your random string.

`APP_BASE_URL`: default is "http://localhost:8000"

`DB_USERNAME`: your PostgreSQL database username

`DB_PASSWORD`: your PostgreSQL database password

`DB_HOST`: your PostgreSQL host

`DB_PORT`: default is 5432

`DB_PATH`: your PostgreSQL database name

### Scripts

When running locally for the first time or whenever updating the database tables, you have to migrate model changes into the database:
- Alembic migration:
```sh
alembic upgrade head
```

- Start local server:
```sh
scripts/start_local.sh
```

- Test scripts:
```sh
scripts/run_tests.sh
```

- Format source code:
```sh
scripts/format.sh
```

## API Reference

#### Get all books

```HTTP
  GET /api/v1/books
```

| Parameter | Type     | Example            | Default |
| :-------- | :------- | :------------------|:--------|
| `title`   | `string` | adventure          |         |
| `author`  | `string` | George             |         |
| `date`    | `string` | before2018-11-04   |         |
| `page`    | `int`    | 3                  |   1     |
| `limit`   | `int`    | 5                  |   5     |

- Filter Date before time
    - use param: `date=beforeYYYY-MM-DD`
    - https://jimmypham.xyz/api/v1/books/?title=en&date=before2022-11-09&page=3&limit=5
- Filter Date after time
    - use param: `date=afterYYYY-MM-DD`
    - https://jimmypham.xyz/api/v1/books/?title=en&date=after2014-11-19&limit=5
- Filter Date exact time
    - use param: `date=YYYY-MM-DD`
    - https://jimmypham.xyz/api/v1/books/?date=2015-09-16

#### Register / Create User

```HTTP
  POST /api/v1/users
```

| JSON Body | Type     | Description |
| :-------- | :------- | :-----------|
| `email`   | `string` | **Required**|
| `password`| `string` | **Required**|
